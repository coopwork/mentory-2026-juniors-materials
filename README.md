## 🌱 Что будем изучать

| Раздел | Основные темы |
| --- | --- |
| 1. Введение в разработку | Интернет, HTTP/HTTPS, DevTools, VS Code, Node.js, npm, GitHub и AI-инструменты |
| 2. HTML | Семантика, структура страницы, формы, валидация, основы доступности и SEO |
| 3. CSS | Каскад, box model, Flexbox, Grid, адаптивность, анимации и введение в Tailwind |
| 4. JavaScript Basics | Типы данных, условия, циклы, функции, массивы и объекты |
| 5. DOM | Элементы страницы, события, формы, динамический интерфейс и browser storage |
| 6. Advanced JavaScript | Замыкания, this, модули, promises, async/await, fetch и REST API |
| 7. Git & Team Workflow | Ветки, pull request, конфликты, code review и командный проект с API |
| 8. React Basics | Vite, JSX, компоненты, props, state, события, формы и списки |
| 9. React Hooks | useEffect, переиспользуемые компоненты, lifting state и React Router |
| 10. TypeScript Intro | Types, interfaces, типизация props/state и внедрение в React-проект |
| 11. Modern React Ecosystem | Zustand, TanStack Query, React Hook Form, Material UI и shadcn/ui; обзор Ant Design |
| 12. Architecture & Best Practices | Структура приложения, оптимизация, JWT, protected routes и clean code |
| 13. Production Workflow & Career prep | Deploy, env, README, портфолио, junior-интервью и финальный проект |

AI-инструменты используются на протяжении курса для анализа кода, поиска ошибок, рефакторинга и работы с документацией.

## 🛠 Практика и результат

- Домашние задания для закрепления изученных тем.
- Лайвкодинг и разбор кода.
- **Team Project** — командная работа с интеграцией API.
- **Full SPA Application** — итоговое приложение на **React, TypeScript, Zustand и TanStack Query**.
- Подготовка проекта для портфолио и разбор junior-вопросов на собеседованиях.

Условия заданий и критерии проверки будут публиковаться по мере подготовки материалов.

## 🚀 Как пользоваться репозиторием

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/coopwork/mentory-2026-juniors-materials.git
   cd mentory-2026-juniors-materials
   ```

2. Перед работой обновляйте материалы:

   ```bash
   git pull
   ```

3. Изучайте материалы текущего занятия и выполняйте задания. Способ сдачи смотрите в условии конкретной работы и LMS.
4. Следите за заданиями и результатами в [LMS Mentory](https://edu.mentory.pro/dashboard).
